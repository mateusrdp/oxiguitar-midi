# Requirements and assumptions

## Requirements

- OxiGuitar 0.21 or later (plugin interface 1.9). See [the OxiGuitar manual](https://mateusrdp.github.io/oxiguitar/).
- Windows, macOS or Linux.
- An audio output plugin to send the sound to your speakers.
- At least one sound set. Every system comes with a basic General MIDI one.

## Assumptions

- A larger recorded set takes memory and disk. SFZ samples are loaded whole, so big sets need room.
- You are allowed to use the sets you install. Each set keeps its own licence.
- The `soundfonts` folder is where sets live. Another folder works if you list it in OxiGuitar's `settings.json`.

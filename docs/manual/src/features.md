# Features and their tests

Everything the MIDI sound plugin does, and the tests that check it. The test names are the ones `cargo test` prints. `scripts/test-all.py` fails when a feature here names no test, or names a test that doesn't exist, so a new feature gets its row and its tests in the same pull request (the [Testing](testing.md) page says how to run them).

| Feature | What it does | Tests |
| --- | --- | --- |
| Plays out of the box | The system's own General MIDI set plays when there's nothing better: a DLS set (Windows, macOS) or a SoundFont (Linux's). | `dls::tests::the_systems_dls_set_plays_when_there_is_one`, `sf3::tests::musescore_general_decodes_when_the_system_has_it`, `settings::tests::only_the_systems_sets_are_basic` |
| Finds sound sets | The user's `soundfonts` folder, then the installed and the system's sets, the larger before the smaller; a set reached twice counts once; subfolders only so deep. | `sets::tests::the_users_sets_come_first_then_the_larger`, `sets::tests::a_set_reached_twice_counts_once_and_missing_places_are_skipped`, `sets::tests::subfolders_are_looked_into_only_so_deep`, `sets::tests::sfz_instruments_are_found_but_not_the_files_they_include` |
| SoundFont 2 and 3, DLS | Reads SF2 and compressed SF3 files, and turns DLS sets into SoundFonts; damaged files are errors, never panics. | `sf2::tests::rustysynth_reads_what_we_write`, `sf3::tests::an_uncompressed_set_comes_back_alike`, `sf3::tests::a_soundfont_2_is_no_soundfont_3`, `sf3::tests::a_damaged_file_is_an_error_not_a_panic`, `dls::tests::a_small_dls_becomes_a_soundfont_rustysynth_reads`, `dls::tests::its_notes_sound_at_their_pitch`, `dls::tests::damaged_files_are_errors_not_panics` |
| RIFF files read safely | The chunk reader under SoundFont and DLS checks every length, forgives a missing pad byte and never reads past the end. | `riff::tests::a_file_s_chunks_and_lists_are_read_in_order`, `riff::tests::a_missing_pad_byte_is_forgiven`, `riff::tests::damaged_files_are_errors`, `riff::tests::numbers_are_read_little_endian_and_only_when_whole` |
| SFZ instruments | Reads SFZ text (includes, defines, headers, opcodes, curves), its regions and samples (WAV, FLAC, Ogg Vorbis), and says what it doesn't know or can't find. | `sfz::text::*`, `sfz::region::*`, `sfz::instrument::*`, `sfz::sample::*`, `sfz::tests::an_instrument_loads_with_its_samples_shared_and_the_missing_said`, `sfz::tests::an_instrument_without_regions_or_samples_is_refused` |
| The SFZ sampler | Pitch by key and rate, band-limited resampling, envelopes as sfizz's, velocity layers and curves, round robins, key switches, loops, release samples, hi-hat chokes, equal-power pan. | `sfz::sampler::*`, `sfz::sinc::*` |
| The recommended SFZ sets' articulations | Recognises the sets the sound-set installer installs, and plays their recorded hammer-ons, palm mutes and drum keys. | `sfz::maps::tests::the_recommended_sets_are_recognised_by_their_files`, `sfz::maps::tests::drums_move_to_the_kits_keys`, `play::tests::an_sfz_sets_articulations_come_from_its_map`, `play::tests::an_sfz_hammer_on_plays_the_sets_recorded_ones`, `play::tests::an_sfz_hammer_on_carries_on_the_ringing_string`, `play::tests::an_sfz_palm_mute_ends_early_without_a_map`, `play::tests::an_sfz_kits_drums_move_to_its_keys` |
| Eight rows of instruments | Every track falls into a role (clean, overdriven and distorted electric, nylon, steel, bass, drums, everything else); a set that names its role plays it without a pick; old picks still hold. | `settings::tests::tracks_fall_into_the_eight_roles`, `settings::tests::sets_that_name_a_role_play_it_without_a_pick`, `settings::tests::a_pick_holds_while_its_set_is_there`, `settings::tests::the_old_electric_pick_holds_for_the_three_electric_rows`, `settings::tests::the_old_guitars_pick_holds_for_both_kinds_and_sfz_only_where_picked`, `settings::tests::a_set_s_old_acoustic_role_stands_for_nylon_and_steel` |
| Plugins > MIDI Sound Sets | The dialog picks a set per row; OK keeps the picks, Cancel forgets them. | `dialog::picks_are_kept_with_ok_and_forgotten_with_cancel`, `settings::tests::sfz_instruments_are_named_by_their_set_and_their_own_name` |
| A set's own information | `oxiguitar-set.json` beside a set names it, gives its role, licence and credit, and its recommended patch; read leniently, the nearest one wins. | `info::tests::patches_are_named_and_one_is_recommended`, `info::tests::the_file_is_read_leniently`, `info::tests::the_nearest_file_below_the_root_wins`, `settings::tests::a_sets_info_names_it`, `settings::tests::only_the_recommended_patch_plays_unpicked` |
| A track's own sound | The track dialog's Sound section: automatic, another row, or a set of its own; saved with the track. | `track::tests::the_choice_lists_automatic_the_rows_and_the_sets`, `track::tests::a_tracks_pick_is_read_and_saved`, `track::tests::a_track_plays_its_pick_or_its_row` |
| Guitar playing | Strings on channels of their own, a new note on a string ending the last, bends, vibrato, hammer-ons, palm mutes, dead notes, harmonics and slaps, swells and fade-outs. | `play::tests::*` |
| Better sounds advised | With only the basic system set, it says so once and links the sound-set installer; with no set at all, it says where sets go. | `settings::tests::better_sounds_are_advised_with_the_link`, `linux:no_sets::no_set_says_where_with_the_better_sounds_link` |
| Real time | Nothing allocated and no system calls on the audio thread, SFZ included, within its time budget. | `realtime::our_midi_plugin_plays_sfz_in_real_time` |
| A working plugin file | The `.oxp` file keeps the plugin contract, with this repository's SDK version and with the newest release of OxiGuitar. | `contract::the_plugin_file_keeps_the_contract`, `sf2::tests::the_contract_suites_test_set_is_this_one`, `oxiguitar_plugin_checks::the_manifest_matches_the_plugin`, `stage:contract (latest core)` |
